# ไฟล์ในโปรเจกต์

## โฟลเดอร์หลัก

- `index.html` — หน้าแบบฟอร์มลงทะเบียนและแก้ไขข้อมูลผู้ใช้ อยู่ในโฟลเดอร์หลัก
- `main.js` — จัดการส่งข้อมูลใหม่ โหลดข้อมูลเพื่อแก้ไข และอัปเดตผู้ใช้ อยู่ในโฟลเดอร์หลัก
- `management.html` — หน้าแสดงและค้นหารายชื่อผู้ใช้ อยู่ในโฟลเดอร์หลัก
- `manage.js` — โหลด ค้นหา และลบข้อมูลผู้ใช้จากหน้า Management อยู่ในโฟลเดอร์หลัก
- `style.css` — กำหนดรูปแบบและการจัดวางหน้าเว็บ อยู่ในโฟลเดอร์หลัก
- `vite.config.js` — ตั้งค่า Vite และ proxy สำหรับส่งคำขอ API ไปยัง backend อยู่ในโฟลเดอร์หลัก
- `package.json` — ระบุ dependencies และคำสั่งของ frontend อยู่ในโฟลเดอร์หลัก
- `package-lock.json` — บันทึกเวอร์ชัน dependencies ของ frontend อยู่ในโฟลเดอร์หลัก

## โฟลเดอร์ `server`

- `server.js` — สร้าง Express server และเชื่อม route `/users` อยู่ในโฟลเดอร์ `server`
- `users.js` — กำหนด API สำหรับสร้าง อ่าน อัปเดต และลบข้อมูลผู้ใช้ในฐานข้อมูล อยู่ในโฟลเดอร์ `server`
- `databaseFlie.db` — ฐานข้อมูล SQLite ที่เก็บข้อมูลผู้ใช้ อยู่ในโฟลเดอร์ `server`
- `package.json` — ระบุ dependencies และคำสั่งของ backend อยู่ในโฟลเดอร์ `server`
- `package-lock.json` — บันทึกเวอร์ชัน dependencies ของ backend อยู่ในโฟลเดอร์ `server`

## สิ่งที่ได้เรียนรู้

- การสร้างหน้าเว็บและฟอร์มด้วย HTML
- การเลือกและจัดการ element บนหน้าเว็บด้วย JavaScript และ DOM
- การตรวจสอบค่าจากฟอร์มก่อนส่งข้อมูล
- การเรียก API จาก frontend ด้วย Axios
- การสร้าง backend และ API ด้วย Express
- การทำ CRUD: สร้าง อ่าน อัปเดต และลบข้อมูล
- การเชื่อมต่อ API กับฐานข้อมูล SQLite ผ่าน `@libsql/client`
- การใช้ Vite proxy ส่งคำขอจาก frontend ไปยัง backend
- ความแตกต่างระหว่าง `localhost`/`127.0.0.1` กับ `0.0.0.0` เมื่อต้องเชื่อมต่อจากอุปกรณ์อื่น
